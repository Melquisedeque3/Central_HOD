# Como o HOD funciona

1. Tudo que você cria aqui vira uma nota `.md` no vault `Documents/HOD`.
2. Edite no Obsidian quando quiser — depois use **Sincronizar vault**.
3. O painel IA conversa com o Hermes Agent na porta 8642.
